========================================
AuthController
Ruta base: /api/auth
========================================

POST    /api/auth/registro
        Registrar usuario nuevo
        Datos requeridos:
        - nombre
        - email
        - password
        - rol (MAESTRO o ALUMNO)

POST    /api/auth/login
        Iniciar sesión
        Datos requeridos:
        - email
        - password

GET     /api/auth/me?idUsuario={id}
        Obtener información de un usuario

CursoController
Ruta base: /api/cursos
========================================

GET     /api/cursos
        Listar cursos
        Parámetros opcionales:
        - idUsuario
        - q
        - idMaestro

GET     /api/cursos/{id}
        Obtener curso por ID

GET     /api/cursos/{id}/alumnos
        Ver alumnos inscritos
        Parámetros:
        - idUsuario
        Parámetro opcional:
        - q

POST    /api/cursos
        Crear curso

POST    /api/cursos/unirse
        Unirse a un curso mediante código
        Parámetro:
        - idUsuario

POST    /api/cursos/{id}/codigo
        Generar nuevo código de invitación
        Parámetro:
        - idUsuario

PUT     /api/cursos/{id}
        Editar curso

DELETE  /api/cursos/{id}
        Eliminar curso

DELETE  /api/cursos/{id}/alumnos/{idAlumno}
        Dar de baja alumno de un curso
